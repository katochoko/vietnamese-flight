# ことばフライト — ベトナム語

日本語が分かる学習者向けの、スマホで遊べる語彙学習ゲームです。ログイン不要。

## 遊び方

1. レベル → テーマ → 20語のセットを選ぶ。
2. 単語一覧で予習し、最大2分間のゲームを始める。
3. 初回はベトナム語→日本語。各セットの2回目以降は両方向を約半分ずつ出題する。
4. 結果から未学習の単語を続けるか、間違えた単語を復習する。

魔法使い・鳥・飛行機を選べます。性能は同じです。新規利用時は飛行機です。飛行機は青空、魔法使いは月夜、鳥は街の背景になります。

### ルール

- 初期高度50、上限100。正解＋8、不正解−18。
- 回答を待つ間は毎秒1.2ずつ下降。答え合わせ中は下降を止める。
- 全問正解なら20語を2周して「学習クリア」。間違えた場合は一巡後、正解済み2問と復習1問を出題し、復習対象0語で「学習クリア」。2周目の間違いも復習に切り替える。
- 復習だけのゲームは対象語をすべて正解すると「学習クリア」。
- 120秒で「今回のフライト終了」、高度0で「ゲームオーバー」。
- 学習クリアと時間終了では最後の高度を保って城へ横移動する。下降演出は墜落時のみ。
- 未出題・未回答は不正解にせず、次回に優先する。
- 最初の一巡までは同じ単語を繰り返さない。背景は右から左へ連続して流れ、キャラクターは回答の進行に合わせて右へ移動する。
- 一時停止と、タブを隠した際は時間・高度を停止する。
- キーボードの1〜4で回答、Escで一時停止・再開できる。

### 学習記録

各回答後にブラウザーのlocalStorageへ保存します。端末間の同期はありません。ブラウザーデータの消去で記録も消えます。前回のセットを「続きから学ぶ」で開けます。ゲームの残り秒数そのものは再開しません。

異なるゲームで2回正解すると習得済みです。連続でなくてもよく、同じゲーム内では1回分だけ進みます。習得後に間違えても習得は維持し、復習対象に追加します。正解すると復習対象から外れます。

「連続正解の累計」は各ゲームの最大連続正解数の合計です。終了前でも達成した分を保存し、終了時に重複加算しません。以前の版には各ゲームの最大連続正解がないため、この累計は更新後から開始します。既存の回答記録・キャラクター・習得に利用できる記録を引き継ぎます。v1の保存データは初回移行時にバックアップします。

## 単語データ

| レベル | 語・表現 | セット |
|---|---:|---:|
| A1 | 400 | 20 |
| A2 | 500 | 25 |
| B1 | 600 | 30 |
| B2 | 500 | 25 |
| 合計 | 2,000 | 100 |

2,000件は表記の重複を除いた見出し語・複合語・定型表現です。言語学的な語根数ではありません。日本語訳とレベル分類は初期教材案で、ネイティブ講師による全件校閲済みではありません。CEFRの公式語彙リストや、各レベルの完全な網羅を示すものではありません。教材として使いながら難易度・訳・紛らわしい選択肢を調整してください。

`words.js` がアプリのデータ、`vocabulary.csv` が確認・編集用の一覧です。CSVの変更は自動ではアプリに反映されません。162件は既存のVietnamese Stepの語彙問題と表記が一致し、訳は今回の4択用に整理しています。`legacy-match` はこの一致を表し、専門家による校閲済みの意味ではありません。

## 音声

初期状態はオフです。オンにすると、ベトナム語の問題は表示時、日本語の問題は答えを先に明かさないよう回答後に、端末のベトナム語音声を再生します。HoaiMy / NamMinhがある場合は優先し、それ以外は端末のベトナム語音声を使用します。声・方言・提供状況はOSとブラウザーに依存するため、全端末で北部音声は保証しません。音声がなくてもすべての学習機能を使えます。音声の終了を待たず回答できます。

## 公開とファイル

HTML/CSS/JavaScriptだけで動作し、サーバー側の処理・APIキー・外部データベースは不要です。GitHub Pagesでmainブランチのルートを公開できます。学習結果をサーバーに送信しません。WebフォントはGoogle Fontsを使用し、取得できない場合は端末のフォントを使います。

空の背景画像は、このアプリのために生成したオリジナル画像です。キャラクターには端末の絵文字を使います。

## 検証

- 100セット×20件、見出し語2,000件の一意性、4択の件数と文字列重複。
- 正解・不正解の高度変化、二重タップ防止、未回答の持ち越し、復習、停止、保存。
- 高度上限、墜落、120秒でのフライト終了、異なるゲームでの習得判定。
- スマホ幅でのゲーム表示、実際のブラウザーでの学習フロー。

対応ブラウザーでのみ、進捗読み取りとセットを開くWebMCPツールも登録します。未対応でもゲームは動作します。
